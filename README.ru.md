# ⛏️ EscapeTheMine (ETM)

**EscapeTheMine** — это динамичный мини-режим для Minecraft 1.12.2, вдохновленный классическими играми про побег из тюрьмы. Игроки делятся на две команды: бдительную Охрану и находчивых Заключенных.

## 🎮 Суть игры

### 🔒 Заключенные 
Ваша цель — совершить дерзкий побег!
*   **Починка:** Ищите верстаки, разбросанные по карте, и чините их, кликая правой кнопкой мыши.
*   **Взаимовыручка:** Если товарища схватил охранник или он томится в камере — ударьте его, чтобы освободить!
*   **Побег:** Почините все верстаки до истечения времени, чтобы открыть путь к свободе.

### 👮 Охрана
Ваша задача — пресечь попытку бунта!
*   **Поимка:** Бейте заключенных железным мечом, чтобы схватить их.
*   **Конвоирование:** Схваченный зэк будет следовать за вами. Ведите его прямо в камеру.
*   **Победа:** Поймайте всех заключенных или удерживайте их до конца таймера.

## ✨ Особенности
*   **🌐 Система Мультиарен:** Полная поддержка запуска нескольких независимых игр одновременно на одном сервере.
*   **Scoreboard Teams:** Индивидуальные префиксы `[З]` и `[О]`, а также цветные ники в TAB и над головой для каждой арены.
*   **Система прогресса:** Динамическая полоска починки (Action Bar) с таймером, уникальная для каждого матча.
*   **Честный рандом:** Улучшенный алгоритм распределения ролей (Double Shuffle), исключающий "застревание" роли на одном игроке.
*   **Защита от багов:** Проверки на дистанцию, запрет действий из тюрьмы и логика освобождения союзников.

## 🛠️ Команды и права
Управление аренами осуществляется через консоль или игру:
* `/etm join <arena>` — Вход на указанную арену.
* `/etm create <arena>` — Создание новой арены из шаблона.
* `/etm spectate <arena>` — Наблюдение за игрой.
* `/lobby`  — Выход в лобби
