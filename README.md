# ⛏️ EscapeTheMine (ETM)

**EscapeTheMine** — это динамичный мини-режим для Minecraft 1.12.2, вдохновленный классическими играми про побег из тюрьмы. Игроки делятся на две команды: бдительную Охрану и находчивых Заключенных.

## 🎮 Суть игры

### 🔒 Заключенные 
Ваша цель — совершить дерзкий побег!
*   **Починка:** Ищите верстаки, разбросанные по карте, и чините их, кликая правой кнопкой мыши.
*   **Взаимовыручка:** Если вашего товарища схватил охранник или он уже томится в камере — ударьте его, чтобы освободить!
*   **Побег:** Почините все верстаки до истечения времени, чтобы открыть путь к свободе.

### 👮 Охрана
Ваша задача — пресечь попытку бунта!
*   **Поимка:** Бейте заключенных железным мечом, чтобы схватить их.
*   **Конвоирование:** Схваченный зэк будет следовать за вами. Ведите его прямо в камеру.
*   **Победа:** Поймайте всех заключенных или удерживайте их до конца таймера.

## ✨ Особенности 
*   **Scoreboard Teams:** Автоматические префиксы `[З]` и `[О]`, а также синие/красные ники в табе и над головой.
*   **Система прогресса:** Наглядная полоска починки с таймером игры.
*   **Честный рандом:** Улучшенный алгоритм распределения ролей.
*   **Защита от багов:** Проверки на дистанцию взаимодействия, запрет починки из тюрьмы и анти-чит логика освобождения.

---

## 🛠️ Команды и права
На данный момент проект находится в стадии активной разработки. Основные команды управления:
* `/etm start` — Запуск игры для всех подключенных игроков.
* `/etm stop` — Принудительная остановка текущей сессии.
* `/etm setloc <type>` — Настройка точек спавна и зон генерации верстаков.
